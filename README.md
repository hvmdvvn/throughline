# Throughline

AI-assisted requirements and delivery workflow for product teams. Connects Jira history to diagnostic analytics and a PM review loop for specs, clarifications, and change watch.

See [`_docs/PLAN.md`](_docs/PLAN.md) for the build plan and [`_docs/TASKS.md`](_docs/TASKS.md) for the backlog (tracked as GitHub issues).

## Stack (planned)

Django + DRF, Celery + Redis, Postgres 16 with pgvector, Next.js, Docker.
